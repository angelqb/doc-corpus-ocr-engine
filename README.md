# 文档离线识别入库引擎（全平台）

**一句话**：在自己电脑上把一批材料离线读成能用关键词搜索的正文库，材料不用上传任何网站。

- 本仓库发布的是**全平台技能包 v1.0**（Windows / macOS / Linux，包内自带 7 个平台的离线解析组件），下载即完整可用。
- 另外还有一个**精简版**，用于上传第三方技能平台（那边对上传包有体积限制）：流程与功能一致，只是包内不带解析组件，
  电子版解析质量略降。两者按同一份源码构建，可按需选用。

## 用法（三步）

1. **解压** zip，得到目录 `文档离线识别入库引擎/`。
2. **装依赖**（在该目录内执行，需联网一次，约 265 MB，装一次长期可用）：

   ```bash
   python tools/setup_env.py
   ```

   > 一条命令装齐：OCR 识别引擎 + 电子版转换组件。**缺一不可** —— 少装了，Word / Excel / PPT 会转不出来。
   > （`--all` 是「再点名装一次转换组件」的保险开关，装齐了就不必带。）

3. **体检**：

   ```bash
   python tools/setup_env.py --check
   ```

   看到「✅ 可以跑全链路」即可开始。

**前置**：Python 3.10+；**电子版分支另需本机有 node 20+**（包内解析组件靠它运行）。
没有 node 也能用：扫描件、盖章件、字体乱码件、照片、截图（OCR 分支）**完全不受影响**；
电子版会退到 Python 转换，解析层级与表格保真略降，仍一份不漏。

具体怎么喂材料、产出什么、有哪些开关，见包内 `SKILL.md`。

## 它产出什么

- 一个能用关键词检索的**正文库目录**（纯文本，系统搜索或 grep 即可查）；
- 一张**覆盖度审计表**：这批材料覆盖了哪些要求条目、哪几条还没被覆盖，用于判断资料是否齐套。

## 三个好处

- 全程在本机跑，**材料不出网**（不调用任何云端接口）；
- 中途断了能**接着跑**，不用从头来；
- 几十上百份**一起处理**，不用一份份点。

## 实测参考

一批 100 份 / 3,417 页，约 3.85 秒一页，识别置信度 0.96–1.00，**全程不联网**。
