# 文档离线识别入库引擎（全平台）

**一句话**：在自己电脑上把一批材料离线读成能用关键词搜索的正文库，材料不用上传任何网站。

- 本仓库发布的是**全平台技能包 v1.1**（Windows / macOS / Linux，包内自带 7 个平台的离线解析组件），下载即完整可用。
- 另有**精简版**，用于上传TeleAgengt平台（那边对上传包有体积限制）：流程与功能一致，只是包内不带解析组件，电子版解析质量略降。两者按同一份源码构建，可按需选用。
- **v1.1 新增**：除正文库与审计表外，**再为每份 PDF 另出一份可编辑的 Word（.docx）** —— 见下文「输出产物」。

## 前置环境

- Python ≥ 3.10
- 电子版文档解析（文字层 PDF、Word、Excel、PPT、odt / rtf / epub）：额外需要 Node.js ≥ 20
- 无 Node 不影响扫描件、照片、截图、字体乱码件的 OCR（本地离线识别）；电子版会退到 Python 转换，结构与表格保真略降，仍一份不漏。

## 快速使用（三步）

1. **解压压缩包**，得到目录：`文档离线识别入库引擎/`

2. **安装依赖**（在该目录内执行，需联网一次，约 265 MB，装一次长期可用）：

   ```bash
   python tools/setup_env.py
   ```

   > 该命令一次性安装 OCR 识别 + 文档转换 + Word 导出全套组件；缺失组件会导致 Office 文档无法解析、Word 版导不出。
   > （`--all` 是「再点名装一次转换组件」的保险开关，装齐了就不必带。）

3. **环境自检**：

   ```bash
   python tools/setup_env.py --check
   ```

   输出 `✅ 可以跑全链路` 即可开始批量处理。

> 完整参数、批量任务配置、文件输入输出规则，见包内 `SKILL.md`。

## 输出产物

1. 可全局关键词检索的**纯文本正文库**（系统搜索、grep 均可直接检索）；
2. **资料覆盖度审计表**：自动统计文档对应条目完成情况，用于核验资料是否齐套；
3. **Word 版成品（.docx）**：每份 PDF 另出一份可编辑的 Word，与原件基本同一套版式 ——
   - **电子版 PDF**：按原件的**分页 / 表格 / 图片 / 段落层级**还原（可编辑、可检索）；
   - **扫描件 / 字体乱码件**：用本地识别出的文字重新排版（可改可搜），版式与原扫描件会有出入（扫描件先识文字再排版的固有限制）。

## 核心优势

- **材料不出网**：处理全程在本机完成，不上传任何文件（仅首次安装依赖需联网一次；本技能不含任何出网路径）；
- **断点续跑**：任务中途中断可继续执行，无需从头重新处理；
- **批量并行处理**：支持一次性导入几十至上百份文档自动处理。

## 性能实测

测试样本：100 份扫描件 + 字体乱码件（走本地离线 OCR 分支），合计 3,417 页；
处理速度：约 3.85 秒 / 页；识别置信度 0.96–1.00；**全程离线运行，无需联网**。
（电子版走结构化解析分支，实测约 0.6 秒 / 份。）

## 边界说明

- 支持格式：PDF、图片（JPG / PNG）、Word、Excel、PPT，以及 odt / rtf / epub 等电子版格式和字体乱码件；
- 仅扫描件、照片、截图：无需 Node 环境，纯 OCR 即可正常识别；
- Word 版式还原针对**电子版 PDF**；扫描件为「识别后重排版」，版式不保证与原件一致；
- 本项目仅做本地文档处理，不收集、不上传任何用户文档数据。
